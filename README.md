# Gut-Brain-Axis Modulation in Alzheimer's Disease: A Multiomics Approach

Integrated multiomics analysis of gut microbiome, saliva microbiome, and plasma metabolomics data to predict Alzheimer's disease severity and identify gut-brain axis biomarkers.

## Overview

This project applies machine learning to a multiomics dataset of 73 participants to classify Alzheimer's disease severity (ADAS groups: Low, Medium, High) and to identify biomarkers linking peripheral molecular changes to cognitive decline.

## Dataset

| Omics Layer | Samples | Features (raw → processed) | Platform |
|---|---|---|---|
| Gut microbiome | 78 | 364 → 125 | 16S rRNA sequencing |
| Saliva microbiome | 78 | 239 → 96 | 16S rRNA sequencing |
| Plasma metabolomics | 87 | 1,143 → 910 | LC-MS |
| Clinical variables | 87 | 48 | Clinical records |
| **Integrated dataset** | **73** | **1,179 total** | Patients present in all layers |

## Pipeline

1. **Data loading:** reads the four raw CSV files and keeps only patients present in all of them (73 samples).
2. **Preprocessing:** removes features with more than 50% missing values, applies median imputation, removes low-variance features (variance below 0.1), and standardizes each layer.
3. **Integration:** concatenates the gut, saliva, and metabolomics layers (prefixed `GUT_`, `SALIVA_`, `METAB_`) and merges the clinical variables.
4. **Exploratory analysis:** clinical variable plots and boxplots of the most variable features in each layer.
5. **Dimensionality reduction:** PCA, t-SNE, and UMAP for each omics layer, colored by ADAS group.
6. **Feature selection:** top 50 features by ANOVA F-statistic plus top 50 by Spearman correlation with ADAS-COG score. The union gives 79 features.
7. **Modeling:** Random Forest, XGBoost, and Logistic Regression evaluated with stratified 5-fold cross-validation.
8. **Feature importance:** Random Forest importance ranking, plus recursive feature elimination (RFECV).

## Key Results

| Model | Mean accuracy (5-fold CV) |
|---|---|
| Random Forest | 67.0% ± 15.4% |
| XGBoost | 61.5% ± 10.5% |
| Logistic Regression | 59.0% ± 12.7% |

- Random Forest performed best.
- Plasma metabolomics contributed most of the selected features (67 of 79).
- Top features: beta-alanine, kynurenine, phosphatidylethanolamine species, *Paraprevotella clara*, and *Gemmiger formicilis*.

```bash

python run_pipeline.py
```

Figures are saved to `results/figures/` and tables to `results/tables/`.

## Limitations

Cross-sectional design, small sample size (n=73), no dietary covariates, and a single cohort. Feature selection is performed on the full dataset before cross-validation, so the reported accuracies may be optimistic.
